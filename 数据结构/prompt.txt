# Role
你是一个计算机专业的大二学生。现在你需要完成一份名为《内部排序算法比较》的课程设计报告。

# Task
编写一个排序算法性能测试程序，并生成配套的 C++ 源代码 `SortComparison.cpp` 和实验报告 `Report.md`。

# 功能要求
1. **排序算法实现**：
   - 必须包含：直接插入排序、希尔排序、冒泡排序、快速排序、简单选择排序。
   - 选做包含（请务必实现）：堆排序、归并排序。
2. **数据处理**：
   - 使用随机数生成器产生待排序数据。
   - 实现计数器：记录每个算法的“关键字比较次数”和“关键字移动次数”。
   - 计时功能：计算每个算法的实际运行耗时（使用 <chrono> 或 clock()）。
3. **测试规模**：
   - N=100：输出排序前后的结果。
   - N=1,000 / 100,000 / 1,000,000：对比各算法耗时。
   - N=100,000,000（一亿）：仅对比快速排序、希尔排序、堆排序和归并排序（注意：要提醒用户 $O(n^2)$ 的算法在此时应跳过，否则耗时过长）。
4. **特殊数据**：观察并记录“完全正序”和“完全逆序”情况下各算法的表现。
5. **代码风格**：全中文交互界面，注释清晰，逻辑易懂，使用结构化编程或简单的类封装。

# 报告要求 (Markdown 格式)
1. **问题描述和需求分析**：说明任务是通过随机数据比较不同排序算法的性能指标（比较次数、移动次数、耗时）。
2. **概要设计**：列出程序包含的各个排序函数名。说明如何保证每个算法测试的数据是完全一样的（比如每次测试前重新拷贝原始随机数组）。
3. **详细设计**：用文字简单描述各算法的逻辑（如：快排的分治思想、希尔排序的增量缩减）。
4. **调试分析**：
   - **重点**：展示一个简单的测试结果表格（包含 1000 和 10万数据量的耗时对比）。
   - 讨论为什么快速排序在逆序情况下可能退化。
   - 讨论为什么冒泡排序在数据量大时极其缓慢。
   - 分析不同算法的空间复杂度。
5. **用户使用说明**：说明如何选择测试规模，以及程序如何输出结果。
