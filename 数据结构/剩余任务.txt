# Role
你是一个计算机专业的大二学生，正在完成《数据结构》课程设计实验。

# Task
题目是《停车场管理》。你需要生成两个文件的内容，并将它们放在一个名为“停车场管理”的虚拟文件夹下：
1. `ParkingManager.cpp` (源程序)
2. `Report.md` (实验报告)

# 核心业务逻辑要求
1. **数据结构**：
   - **停车场**：使用栈（Stack）模拟，限制容量为 n。
   - **便道**：使用队列（Queue）模拟。
   - **临时让路空间**：再使用一个栈，用来临时存放为了给离去车辆让路而退出的汽车。
2. **车辆信息**：结构体需包含车牌号、到达或进入车场的时间。
3. **功能操作**：
   - **到达 (A)**：若停车场未满，直接进入并记录时间；若已满，进入便道等候。
   - **离去 (D)**：
     - 若车在停车场，计算停留时间并按费率计费（需处理让路逻辑：后进的车先出栈进入临时栈，目标车出场后，临时栈的车再回场）。
     - 目标车走后，若便道有车，则便道首辆车进入停车场，并以当前时间作为入场时间。
   - **结束 (E)**：退出程序。
4. **代码细节**：
   - 全中文交互界面（如：“请输入操作类型(A/D/E): ”）。
   - 全中文代码注释。
   - 费率自定（例如每小时2元，或每单位时间1元）。
   - 严格按照题目给出的测试数据进行逻辑校验。

# 报告要求 (Markdown 格式)
1. **问题描述和需求分析**：说明停车场（栈）和便道（队列）的模拟规则。明确输入输出格式。
2. **概要设计**：文字描述栈和队列的选择原因。描述停车场管理的三个核心状态：入场、出场、便道候车。
3. **详细设计**：用文字详细描述“车辆离去”时的算法步骤（包括让路逻辑）。
4. **调试分析**：
   - 讨论遇到的难点：比如如何计算停留时间？让路车辆回场时的顺序如何保证不变？
   - 讨论测试数据：针对题目给出的 (n=2) 的案例进行运行结果分析。
   - 经验体会：谈谈栈和队列在实际场景（如停车场）中的应用感受。
5. **用户使用说明**：说明 A, D, E 命令的输入方法和参数含义。
